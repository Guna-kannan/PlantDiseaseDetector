1. Executive Summary & Project Overview

PlantDiseaseDetector is an end-to-end automated plant pathology diagnosis system engineered to classify leaf diseases across Tomato, Potato, and Bell Pepper crops. Leveraging a custom 6-block Deep Convolutional Neural Network (CNN) trained on the curated PlantVillage dataset, the system processes raw leaf photographs and returns:

  • Predicted disease class name and confidence score (%)
  • Calculated severity level (None, Moderate, High)
  • Specific agronomic treatment recommendations
  • Top 3 candidate diagnostic predictions with confidence distribution
  • Crop status boolean indicator (is_healthy)

The system is engineered as a cloud-native microservice with complete implementation of modern DevOps standards spanning Linux system administration, Podman rootless containerization, OCI image lifecycle, multi-container Docker Compose with Nginx reverse proxy, and enterprise multi-pod orchestration for Kubernetes and Red Hat OpenShift.

3. Model Evaluation Results & Training Curves

The model was trained on an 80/10/10 split (Train/Validation/Hold-out Test) using Adam optimization and sparse categorical cross-entropy with early stopping on validation loss.

6. Application Architecture Diagram

Architecture Summary:
Clients connect via HTTP to the Nginx Reverse Proxy (port 8080) or Kubernetes/OpenShift Ingress/Route. Nginx forwards requests over the internal isolated network (plant-net) to the FastAPI Application (port 8000). The FastAPI application evaluates leaf images using the pre-loaded TensorFlow CNN Model and returns JSON predictions and UI templates. Model weights and uploads are persisted using persistent volume claims (PVCs) and host bind mounts.
